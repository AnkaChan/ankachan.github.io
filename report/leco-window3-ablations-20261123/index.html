Learned Cloth Optimizer · rerun of 23 November 2026

All ablations with history window 3

Every ablation of the optimizer network was trained again with a history window of 3. The network then reads the gradient and the applied update of each of the last 3 iterations, not only of the last one. This page compares each new model with the old model of the same variant.

Findings

State: 36 of 38 models. The 16-ring and 32-ring variants of the per-node scale are still training. “×” is the gradient norm at the end of the step relative to a baseline; below 1 is better.

  1. The old conclusions hold. 30 of the 36 variants keep their verdict against the baseline when both have window 3. The window changes the level of the results, not their order.
  2. The window helps most variants by about the same factor as the baseline. The baseline gains 0.77×. Of the 24 variants that complete all rollouts with both windows, 20 gain with window 3, most of them between 0.66× and 0.89×.
  3. No variant is clearly better than the window-3 baseline on all criteria. The three best variants are the standard GNN with edge latents (0.82×), context depth 3 (0.82×) and context depth 5 (0.83×). Each of them loses clean runs on 00756 (2, 1 and 0 of 3; the baseline has 3 of 3).
  4. The window and a larger context overlap. With window 1 the same three variants were at 0.71× to 0.75× of their baseline. With window 3 the gain is smaller (0.82× to 0.83×). Against the original baseline they reach 0.62× to 0.64×, the lowest gradient norms of all models.
  5. The window repairs some weak variants. “No current gradient” and “last update / RMS” failed their rollouts with window 1 and complete all four with window 3 (5.78× and 2.09×). Hinge edges (1.23× → 0.96×), the adaptive initial guess (1.15× → 1.00×) and per-node normalization + magnitude (1.84× → 0.94×) reach the level of the baseline. The last one has no clean run on 00756.
  6. A per-node step scale still fails. All 10 evaluated variants with a per-node scale diverge in the rollout, with both windows. In the fixed-state test the ring variants miss about half as much as with window 1, but this does not carry over to a rollout.
  7. The window does not help the output-direction variants and the variants without a learned scale. “Direction / RMS, global scale” gets worse (1.07× → 2.02×, clean runs on 00756 from 2 of 3 to 0 of 3). “Unit direction per vertex” goes from 19× to 57×. “No scale” and “no iteration” stay far from the baseline.
  8. The history inputs still matter with window 3. Without the last updates the model is at 2.02×, without the previous gradients at 1.42×, without any gradient at 608×. The extra inputs (contact force, inertia gradient, position, cloth state, FiLM) stay within 0.92× to 1.13× of the baseline.

Method

What changed

Only network.history_window: 3. The first layer gets 12 more input channels. The latent width stays 96. Data, schedule (500,000 steps), and training without DAT are the same as for the old models. Each old gradient is divided by the RMS of the current gradient, each old update by the step scale of the last iteration.

The ablations of the width and of the window itself are not repeated.

Limits of these results

  • One training per model. Two trainings of the same configuration differ, so differences of about 10 to 15 % between two models are not resolved.
  • 00756 has three runs per model. A difference of one clean run is not a result.
  • No timing on this page. With a window above 1 the solver uses the plain Python step path, which is slower per iteration than the captured path of the baseline.
  • No model was trained with DAT.
  • “No iteration” trains with one iteration per step. The history is then always empty in training, so the window cannot help this variant.
  • Related pages: all ablation results (window 1, width, and the history window itself) and the network on a tetrahedral cuboid.
  • Branch ankac/leco-tensorcore-inference.
